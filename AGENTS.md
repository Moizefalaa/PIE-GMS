# Proyecto: Pinturillo TEA

Este es un proyecto independiente de juego colaborativo de dibujo.

- Alcance: dibujo, turnos, comunicacion, accesibilidad y experiencia para personas autistas.
- No tratarlo como proyecto 3D ni mezclarlo con Valdivia 3D.
- Priorizar interacciones claras, baja sobrecarga visual y pruebas de usabilidad.
